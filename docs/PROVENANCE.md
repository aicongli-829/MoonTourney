# Source provenance

MoonTourney is an original MoonBit implementation in this repository. It does not vendor source from tournament organizers, bracket websites or sports federation software. Public rule documents inform the disclosed scoring subsets and are linked in [RULES.md](RULES.md); no large passages of those documents are reproduced.

The root library depends only on official MoonBit core packages. There are no external runtime dependencies. Thin Node/browser adapters provide file and DOM access; generated JavaScript is excluded from Git and source-size claims.

The public repository starts with a MoonTourney source snapshot. Earlier local experiments and private application materials are excluded. Tracked UI, documentation, examples and comments are English.

This repository is prepared for public review but does not claim Mooncakes publication, federation certification, real event adoption or hackathon acceptance. Private application forms and research artifacts belong outside tracked source.
