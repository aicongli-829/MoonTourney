# Changelog

## 0.1.0 — MoonTourney

- Introduce a portable MoonBit competition engine and English web desk.
- Add ten formats, including home/away league playoffs, home/away groups and fixed-length Swiss playoffs, ten scoring profiles including organizer-defined open score, rule validation and configurable standings.
- Add upper/lower bracket resolution, conditional reset, byes, groups and Club Swiss.
- Add dependent-result invalidation, withdrawals, undo/redo and JSON persistence.
- Add court/rest planning, safe CSV and Markdown exports, MoonBit CLI and examples.
- Add season collections for Spring/Summer and other recurring events, with independent snapshots, next-season cloning, historical winners, browser management and JSON / CSV exchange.
- Generate a season and suggested daily timetable directly from the setup form; show times, courts and score controls beside each fixture.
- Interleave group matchdays, keep games inside daily playing hours, and advance completed qualifying stages or fixed-length Swiss rounds automatically when standings permit.
- Refresh the web desk with a stronger event header, clearer match and status hierarchy, responsive cards, a live completion indicator and a mobile event shortcut.
- Add behavior tests, integration smoke, portable-target CI and rule-source documentation.
